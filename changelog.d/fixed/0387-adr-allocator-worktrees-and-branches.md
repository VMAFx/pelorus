- `scripts/adr/next-free.sh` now scans all local worktrees (including untracked `.stub` files) and all known branch tips (`refs/heads` and `refs/remotes` via `git ls-tree`) without network access, preventing ADR number collisions across concurrent worktrees and unmerged branches. `--claim` validates topic slugs (`^[a-z0-9][a-z0-9-]*$`), `--release` fails on unknown slots, prunable worktrees are handled safely, and a failed Git call or an exceeded scan cap exits non-zero without printing a number or creating a stub ([ADR-0219](docs/adr/0219-adr-allocator-sees-worktrees-and-branches.md), [#387](https://github.com/VMAFx/pelorus/issues/387)).
