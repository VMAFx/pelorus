- `pelorus_grain_estimate_vulkan` no longer reads heavy grain weak: every luma band is measured at `edge` and at 2 × `edge`, and a band takes the wide statistics when its measurement matches white Gaussian grain. White grain at 6 code values comes back within 0.44% on the mean (was 26.8% weak) and the ramp to 4.75 code values within 0.23% per stripe (was up to 15.4% weak); textured content is unchanged. New AVOption `adapt` (default on; off reproduces the single gate) and frame metadata `lavfi.pelorus.grain_wide_bands`. Heavy AR grain and grain above about 7 code values still read weak ([#414](https://github.com/VMAFx/pelorus/issues/414)) ([ADR-0229](docs/adr/0229-grain-dual-gate.md), [#411](https://github.com/VMAFx/pelorus/issues/411)).
