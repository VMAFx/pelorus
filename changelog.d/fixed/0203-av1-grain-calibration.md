- `pelorus_grain_estimate_vulkan` AV1 output is calibrated against FFmpeg's AV1 grain synthesizer: the scaling function was 73% to 80% too weak and the lag-1 AR coefficient went to the diagonal tap. It now writes a symmetric lag-1 model to the up and left taps and reproduces synthetic grain within 0.2% (white and ramp grain up to about 3.5 code values) and 2.8% (AR grain). The `strength` default changes from 2.0 to 1.0 (1 = reproduce the measured grain); an explicit `strength=2` now doubles the measured grain. Frames above DCI 8K (8192×4320 pixels) fail at configuration with `EINVAL` ([ADR-0227](docs/adr/0227-av1-grain-calibration.md), [#203](https://github.com/VMAFx/pelorus/issues/203)).
