- On NVIDIA, the aa, dehalo, deband, denoise and borderfix Vulkan filters no longer write wrong luma in the last columns of nv12 and nv24 frames whose width is not a multiple of 64, and analyze no longer reports different metadata for those layouts. The shaders take the frame size from specialization constants instead of `imageSize()`, which reports a padded width for these plane views ([ADR-0202](docs/adr/0202-vulkan-plane-size-spec-constants.md), [#358](https://github.com/VMAFx/pelorus/issues/358)).
