- `pelorus_grain_estimate_vulkan` no longer reads heavy AR grain weak: a band that behaves like grain climbs a chain of gates, 1, 2 and 4 × `edge`, the lag-1 correlation is taken at the gate each band took, and bands above the default gate map to AV1 through a calibration measured through the same gates. AV1 grain at 6.8 code values with a lag-1 AR model comes back within 1.95% on the mean (was 12.5% weak) and the ramp to 7.4 code values within 2% per stripe (was up to 4.8% weak); lighter grain, `adapt=0` and textured content are unchanged. New frame metadata `lavfi.pelorus.grain_gate_steps` ([ADR-0230](docs/adr/0230-grain-gate-chain.md), [#414](https://github.com/VMAFx/pelorus/issues/414)).
