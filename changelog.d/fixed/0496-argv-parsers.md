- Every tracked Python script now parses its command line with stdlib `argparse` instead of indexing `argv`. `scripts/check-mirror-contract.py --list` without a value now exits 2 with a usage message instead of an unhandled `IndexError`. `scripts/windows/check-pe-imports.py` reads its DLL allow-list with `configparser` and now refuses a duplicate entry instead of keeping the last one. The new fast-suite tests `python-argv` and `python-argv-self-test` (`scripts/check-python-argv.py`) keep hand-parsed `argv` out of the tree ([#496](https://github.com/VMAFx/pelorus/issues/496)).
