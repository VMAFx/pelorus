- The script process-tree helpers no longer leak or misreport processes. `scripts/process_tree.py` treats a `PermissionError` from the liveness probe as a live process, keeps the Windows wait error before closing the handle, and ends any resumed child with `TerminateJobObject` before it closes a failed job; a cleanup call that fails is named on stderr without replacing the start error. `scripts/patch_harness.py` stops and reaps the compiler tree on any interrupt, not only on its deadline, so an interrupted harness run leaves no compiler or grandchild running. A failed tree stop is named and the compiler is still killed and reaped, and undecodable compiler output is read with replacement characters instead of failing the capture ([#580](https://github.com/VMAFx/pelorus/issues/580)).
