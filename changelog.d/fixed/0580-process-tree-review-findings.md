- The script process-tree helpers no longer leak or misreport processes. `scripts/process_tree.py` treats a `PermissionError` from the liveness probe as a live process, keeps the Windows wait error before closing the handle, and ends any resumed child with `TerminateJobObject` before it closes a failed job. `scripts/patch_harness.py` stops and reaps the compiler tree on any interrupt, not only on its deadline, so an interrupted harness run leaves no compiler or grandchild running ([#580](https://github.com/VMAFx/pelorus/issues/580)).
