- A curl download that hung was never retried: the attempt ran to `--max-time` and spent the whole `--retry-max-time` window, which had the same value (CI run 42464703696). `scripts/fetch-ffmpeg-series.sh`, `scripts/check-gitleaks.sh` and `scripts/bench/fetch-corpus.sh` now abort an attempt that receives nothing for `CURL_STALL_TIME` seconds (default 30) and retry within `CURL_RETRY_WINDOW` (default twice `CURL_MAX_TIME`); each of the three variables must be a positive integer. The fast-suite gate `scripts/check-curl-retry.py` now refuses a retried download without `--speed-time`, or with a `--retry-max-time` no wider than `--max-time`.
