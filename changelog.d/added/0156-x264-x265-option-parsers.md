- Option-string parsers for x264 and x265 in `libpelorus/include/pelorus/encode_options.h` and `libpelorus/src/encode_options.c` (`pel_encode_options_parse`) that parse and normalise CLI and FFmpeg pass-through parameters (`-x264-params`, `-x265-params`) into arrays of `PelorusEncodeParam` for `pel_encode_record_build()`. Backed by static dialect tables derived from pinned upstream sources (x264 at `b35605ace3ddf7c1a5d67a2eb553f034aef41d55`, x265 at `e444744c03978c1fb4e037168967020cf2648427`), the parser maps aliases, handles boolean negation (`no-` / `no`), normalises types (boolean `"true"`/`"false"`, integer decimal, float `"f64:<hex>"`), preserves unknown or type-rejected options in `unknown_params`, applies last-wins resolution on duplicate keys, and sorts output parameters deterministically with zero heap allocation ([#156](https://github.com/VMAFx/pelorus/issues/156), [ADR-0198](docs/adr/0198-encoder-option-string-parsers.md)).
