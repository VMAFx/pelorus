- `pelorus_fgs` accepts libx265-wrapped user data unregistered (UDU) SEI payloads in `source=sidedata` mode: libx265 prepends its own UUID (`2ca2de09-b517-47db-bb55-a4fe7fc2fc4e`) in front of the caller payload, which `pel_udu_classify` recognizes and unwraps while strictly refusing any other wrapped forms or generic offset-16 retries (ADR-0210).
- `ffmpeg-patches/test/fixtures/udu-wrap-vectors.txt` publishes the accepted and refused user data SEI forms as test vectors; the fast test `udu-wrap` replays them, and `test/fgs-sidedata-smoke.sh` gains an `x265` case and `ENCODER=libx265` (ADR-0210).
