- `pel_encode_options_from_ffmpeg` records FFmpeg encoder AVOptions in the encode record as `ffmpeg:<name>` with verbatim values for libx264, libx265, libsvtav1, libaom-av1 and the NVENC, QSV, VAAPI and Vulkan encoders, so hardware encodes carry their settings and `-preset` or `-crf` changes the digest. Host settings such as `threads` are left out, and an AVOption is dropped only where the option string sets the same encoder fields later (x264/x265 `crf` and `qp`, SVT-AV1 `crf`, libaom `cpu-used`), so `-crf 30 -x264-params crf=20` records the same as `-x264-params crf=20` (ADR-0200).
