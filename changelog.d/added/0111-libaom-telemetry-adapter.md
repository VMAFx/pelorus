- `pel_tlm_from_libaom` converts caller-associated libaom 3.15.2 frame values into AV1 telemetry without a libaom dependency: frame indices, bytes, native and normalized QP, picture type, key status and optional per-plane PSNR. Invalid input leaves output unchanged. Reference and shown status remain unreported; see [the API contract](docs/api/encoder-telemetry.md#libaom-in-process-adapter). Part of [#111](https://github.com/VMAFx/pelorus/issues/111).
