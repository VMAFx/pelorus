- The published Intel tester image installs Debian's `intel-media-va-driver-non-free`, so `hevc_qsv` steering and side-data legs run on Arc A-series GPUs. The package is Expat-licensed; Debian ships it in `non-free` only because Intel's GPU kernels come without source. `tools/tester/licensing.json` records it with that reason, and the licence gate admits a package from outside Debian `main` only when a component records it with a redistributable licence: any other `non-free` or `contrib` package still fails the build, and so do FFmpeg `--enable-nonfree` and the other nonfree components. The `-source` image carries the driver's Debian source package. The local-only `INTEL_MEDIA_DRIVER=nonfree` build, the `intel-nonfree-local` kit and the NOT-FOR-REDISTRIBUTION marker are removed; tester tool 0.4.2 ([ADR-0180](docs/adr/0180-tester-vendor-images.md), [research 0229](docs/research/0229-tester-vendor-images.md)).
