- `pelorus_denoise_vulkan` with `mc=1` and the Vulkan-Video QP-map path now place their shader-read storage buffers (motion grid, confidence grid, ROI list) in device-local memory instead of host memory, so a discrete GPU no longer reads them over PCIe during the dispatch; output is unchanged. The fast suite test `vulkan-buffer-domain` refuses a new host-only storage buffer ([ADR-0222](docs/adr/0222-device-local-storage-buffers.md), [#109](https://github.com/VMAFx/pelorus/issues/109)).
