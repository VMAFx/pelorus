- A release upgrade test now checks the interop side data across versions: `scripts/test-abi-upgrade.sh` builds the previous release and the current tree, packs a blob with each, and reads it back with both. An older reader must parse every section it knows from a newer blob and skip the new ones; a newer reader must accept an older blob with its new sections absent. The candidate steps in `docs/development/release.md` run it, and its `--self-test` proves that a corrupted section and a truncated header are refused. The probe takes a blob name from a fixed list and runs in the build directory, so no command-line path reaches a file open; the self-test proves that a relative, an absolute and an unknown name are refused.
