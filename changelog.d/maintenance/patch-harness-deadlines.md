- The shared C harness of the patch tests (`scripts/patch_harness.py`) now gives the compiler 120 s and the harness binary 30 s, and reports a stall as a failure instead of hanging the fast suite. The new `patch-harness` fast test (`scripts/test-patch-harness.py`) plants a pass, a failure, a compile error, a harness that never exits and a compiler that never exits. Meson test timeouts on each harness test now account for the compile-plus-run deadlines with margin, and the new check `scripts/check-harness-test-timeouts.py` fails if a harness test lacks a timeout or drops below 150 s. Deadlines now terminate the entire process tree via POSIX process groups or Windows taskkill /T before draining pipes, backed by a stalled-child test verifying that grandchildren holding compiler output pipes are killed. If taskkill fails on Windows, the harness still kills the compiler driver and reports the deadline status; the stalled-child test allows a slow start and counts a zombie grandchild as gone.
