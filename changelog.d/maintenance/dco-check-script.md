- The Standards workflow's DCO sign-off check now runs `scripts/check-dco.py` instead of inline shell, with the same rules and messages. It refuses a base or head that is not a plain revision, so a value can never reach git as an option. Its `--self-test` plants twenty cases (missing, malformed and indented trailers, a trailer after a lone CR or U+2028, the Renovate exemption and its two misuses, empty and unknown ranges, a merge commit, the missing count, a branch name with `$`, four refused revisions, git missing from `PATH`), and the fast suite runs it plus a check that it leaves the invoking repository untouched (audit gap C11.4).
