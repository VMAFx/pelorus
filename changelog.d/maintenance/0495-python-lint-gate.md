- `make verify-native`, the pre-commit hook (when a Python file, a workflow or the lint configuration is staged) and the CI `docs` job run Ruff 0.17.3 and zizmor 1.32.0, pinned by hash in `.config/python-lint/requirements.txt`, through `scripts/check-python-lint.sh`; the Ruff rule set mirrors Codacy's, so a Python or workflow finding fails before push. zizmor runs with `--strict-collection`, so a workflow it cannot parse fails too, and the cached tool environment is rebuilt after a lock bump or a half-finished install; `PYTHON_LINT_ENV` may hold a path with spaces (ADR-0243).
