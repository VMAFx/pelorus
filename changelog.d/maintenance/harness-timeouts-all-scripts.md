- `scripts/check-harness-test-timeouts.py` now checks every Meson test that runs a script, not only patch-harness tests: a script whose module-level `*TIMEOUT*` constant exceeds Meson's 30 s default must declare a `timeout:` at least that long. Patch-harness detection reads the syntax tree instead of matching text. Self-test cases cover a missing, a sufficient, a boundary and a short timeout.
