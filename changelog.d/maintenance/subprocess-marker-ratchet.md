- The fast suite now compares per-file counts of unmarked subprocess imports and calls in tracked Python (`scripts/check-subprocess-markers.py`, baseline `scripts/subprocess-markers-baseline.json`). A file whose unmarked count grows fails before push, and a count that drops must be written back to the baseline. Replacing one unmarked site with another in the same file still passes, and the tree check does not run on Windows hosts, so Codacy can still report a new site on the pull request. The self-test also runs with git off PATH, so a planted case that needs git must skip by name.
