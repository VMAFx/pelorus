Its self-test fails on Linux and macOS when `meson`, `ninja` or a C compiler is missing instead of skipping the kit cases, and its tiny project uses `meson_options.txt`, which Meson reads from the 0.57 floor on ([ADR-0248](docs/adr/0248-tester-kit-expected-fail.md)).
