- Gate scripts that turn an unreadable file into a clean error now catch `UnicodeDecodeError` too, so a file with invalid UTF-8 no longer escapes as a traceback; `check-harness-test-timeouts.py` fails on such a script instead of skipping it. The new fast-suite gate `scripts/check-python-decode-errors.py` and its self-test flag any `try` block that guards `Path.read_text()` against `OSError` alone.
