- `make verify-native`, and with it the pre-push gate, now runs `scripts/check-changed-lint.py` against the merge base with `origin/master`. A push fails when it adds a cppcheck finding to a clang-tidy lane unit (findings keyed by file, check id and source line text, so pre-existing debt and shifted lines pass) or when a changed Python line is not `ruff format`-clean (`ruff format --check --range` per hunk). The CI docs job runs the same check on pull requests. Self-test: `python3 -I scripts/check-changed-lint.py --self-test`. The FFmpeg-tree units stay with Codacy, and the `declared-linters` exception for cppcheck leaves `.standards.yaml` ([ADR-0258](docs/adr/0258-changed-code-lint-gate.md)).
