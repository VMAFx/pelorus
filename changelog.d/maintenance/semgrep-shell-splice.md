- The new Semgrep rule `pelorus-shell-splice-into-inline-source` and verification test `scripts/test-semgrep-shell-splice.py` flag shell variable splices (`'"$var"'`, `'"${var}"'`, `'$var'`) into inline interpreter programs (`python3`, `python`, `perl`, `ruby`, `node` via `-c` or `-e`), ensuring arguments are passed safely via `sys.argv` instead of quote closures that rewrite code when a value contains quotes. A second Python `-c` stays quiet, since Python passes it to `sys.argv`; a later `perl`, `ruby` or `node` `-e` is still checked.
