- The `scripts/check-build-config.py` self-test reads the Go pin from `build-config.env` instead of spelling `GO_VERSION=1.27.3`, so Renovate's Go bump no longer fails `build-config-sync` and `build-config-selftest-isolation`. The checker now refuses any script under `scripts/`, `tools/` or `ffmpeg-patches/` that spells a moving pin's current `KEY=value`, and the self-test replays the Renovate fixtures against a bumped `GO_VERSION`. The script scan matches whole keys and whole values across quoted and spaced forms (`KEY = "value"`) and is replayed in `--self-test` at each reachable next version, including `FFMPEG_SERIES_TAG` release-candidate bumps ([#609](https://github.com/VMAFx/pelorus/pull/609), [ADR-0152](docs/adr/0152-renovate-guard-enforcement-scope.md)).
