# Research 0172: tester and release-candidate programme design

Evidence behind the tester items of [ADR-0172](../adr/0172-roadmap-milestone-map.md): how vmafx runs its tester and release-candidate programme (part A), what Pelorus has today (part B), and the work items `T0` to `T17` that map one onto the other (part C). Sources are vmafx paths on `origin/master` unless marked PEL, read 2026-10-08. "Unverified" means not checked against a primary source.

Several open decisions in part D were answered the same day: GPL-3.0-or-later FFmpeg without nonfree components, macOS as a MoltenVK spike, release candidates for every 0.x minor from 0.4. The adopted placement is in [the roadmap](../roadmap.md), epic [#108](https://github.com/VMAFx/pelorus/issues/108).

## A. vmafx tester / RC programme

### A.1 Shape

- Principle: tester artifact = evidence for a master commit, NOT a product release (ADR-1492, 1493). Name = `<git describe>`; GH prerelease `tester-<YYYYMMDD>-<sha8>` / `tester-windows-<date>-<sha8>`; never attached to `v*` release; never `latest`.
- Purpose: outside testers with hardware vmafx lacks (Apple M, Arm servers, AVX-512 Intel, Intel/NVIDIA/AMD GPUs, Windows x64/arm64) run ONE prepared package, no build, offline, get ONE JSON report; credit via PR or issue. (ADR-1342 = from-source predecessor; ADR-1492 = prepared image.)
- Packages (docs/usage/tester-image.md table): macOS arm64 bundle (.tar.xz); CPU image amd64+arm64 `ghcr.io/vmafx/vmafx:<describe>-tester`; GPU images amd64 `-tester-sycl|-cuda|-hip`; Windows zips x64, arm64, x64-cuda, x64-sycl. Each image has companion `<tag>-source`.
- Entry point: `vmaf-tester-report` (images) / `run.sh` / `run.cmd`. Hardening line documented: `--network none --read-only --cap-drop ALL --security-opt no-new-privileges --tmpfs /tmp`; uid 10001.

### A.2 Contents / what the tester runs (tools/rc1-tester/**)

- Python, stdlib only: `src/vmaf_rc1_tester/{probe,safe_process,validate,bundle,cli,hw_report,hw_gpu,hw_{sycl,cuda,hip,metal}*,hw_equiv,hw_gate,hw_rows,hw_suites,hw_winfacts,hw_facts,hw_reference}.py`; launchers `vmaf-rc1-report` (from-source: probe/validate/bundle/list-tools), `vmaf-tester-report` (prepared packages). `image/` = build inputs: `licensing.{py,json}`, `prepare_build.py`, `unit-tests*.txt`, `*-tests.txt`, `*-rows.json` (state-row maps), `*-runtime.json` (vendor files allowed to ship), `published-rc/` (scans of rc images). `GpuBackend` interface (ADR-1505): discover devices, pin run, parse audit, row map. Probes run in bounded child processes (ctypes), no UUID/PCI bus/serial.
- Checks: CPU dispatch equivalence (default vs scalar, `--precision max`), reference equivalence vs scores baked at image build, unit tests (37 SIMD/dispatch exes), Netflix golden gate (python), Metal/CUDA/SYCL/HIP twins vs CPU per fixture + cross-backend parity gate with `--hold-exact`, device tests, scratch audit (SYCL), state-row verdicts (pass/fail/not_measured). Fixtures: Netflix `vmaf_resource` pinned commit c0ab6adb (BSD-2-Clause-Patent), BBB frames (CC BY 3.0 notice, ADR-1503 rule 8).
- ADR-1342 contract (from-source collector): explicit `--backend` only (no auto); CPU always first; PASS needs rc 0 + `backend_used` match + full schema + score in [0,100] + per-frame agreement 5e-5 vs pinned snapshot / vs CPU of same run; exit 0 pass /1 fail /2 incomplete /100 backend unavailable; bundle = report.md + JSON + raw logs + `SHA256SUMS` + manifest (manifest hashes SHA256SUMS; CLI prints whole-archive hash; "no authenticity claim"); redaction of home/repo prefix; failure still writes evidence.
- Report schema: `docs/hardware-reports/report.schema.json`, `schema_version` 3 (+`gpu` section, `metal_gate`, `metal_rows`); `scripts/ci/check-hardware-reports.py` validates (JSON schema, tool-computed integrity hash, `built_by_workflow`, verdict consistency); `no_device` is NOT a failure and must name the missing `docker run` option (hosted runners have no GPU; CI asserts `no_device` + reason).
- Report flow: tester copies `report.json` to `docs/hardware-reports/<date>-<cpu-slug>.json` via PR (credited as commit author; only `note` editable, hash checked) OR opens `.github/ISSUE_TEMPLATE/hardware_report.yml` (fields: report.json, package dropdown, machine, optional credit for `Co-authored-by`; label `hardware-report`); maintainer commits. Index page generated: `scripts/docs/generate-hardware-reports.py`; `docs/usage/hardware-we-need.md` table generated from `scripts/docs/hardware-needs.json` (family -> package -> state row -> status). `make docs-fragments-check` fails when stale.
- Docs: `docs/usage/tester-image.md` (user guide A-F + licences + report contents + send/credit), `docs/usage/rc1-tester-guide.md` (from-source), `docs/usage/hardware-we-need.md`, `docs/hardware-reports/index.md`, `docs/development/tester-image.md` (maintainer runbook: publishing by hand, local checks, licensing), `docs/development/rc3-home-gpu-retest.md`, figure `tester-kit-flow`.

### A.3 Build / publish

- Dockerfile: `docker/Dockerfile.tester` (944 lines): stages fixtures, python-venv, vmaf-build, licence-texts, runtime, refs-gen/refs-export/xref; GPU targets `sycl-build..final-sycl`, `cuda-build..final-cuda`, hip likewise; each has `*-licence-check` and `*-source-fetch/*-source-export`. Base images digest-pinned (debian:13-slim, python:3.14-slim, rocm/dev-ubuntu). Shipped GPU stage = plain Debian + only licence-permitted vendor files; NVIDIA ships NO NVIDIA file (host driver via Container Toolkit, `NVIDIA_DRIVER_CAPABILITIES=compute,utility`; build fails if NVIDIA-named lib appears or NEEDED).
- `.github/workflows/docker-publish-tester.yml` (961 lines): triggers pull_request, push, `schedule` 00:29 UTC nightly (ADR-1701: amd64 only, never publishes, own concurrency group, ends before other nightlies), `workflow_dispatch` (inputs `ref` XOR `tag`, `publish`). Jobs: tier, impact (ci-impact selector `tester_image`, `own_paths_only`, ADR-1700), validate, refs-x86 (45 min), build matrix amd64+arm64 native runners (90 min), `tester-image` aggregator, publish (env `tester-publish`: master-only, maintainer reviewer; cosign keyless sign + `actions/attest-build-provenance` + syft v1.51.1 SPDX SBOM `actions/attest` per platform digest + `gh attestation verify` + `-source` image), build-gpu matrix sycl/cuda/hip (120 min; run WITHOUT GPU and require `no_device`), publish-gpu.
- `macos-tester-bundle.yml` (338): schedule Mon 04:23, dispatch (`ref`|`tag`, `publish`); build on macos-latest arm64 (90 min), Metal on, bundled python-build-standalone (pinned URL+SHA256, `full` archive for licence texts), ad-hoc `codesign -s -` (no Developer ID, no notarisation), `otool -L` check (only /usr/lib, /System/Library), `sandbox-exec` network deny in run.sh; publish: attest + `cosign sign-blob --bundle` + SPDX SBOM asset + prerelease via release-bot identity (job token cannot create tag for commit behind master that differs in .github/workflows/).
- `windows-tester-bundle.yml` (709): push/PR/dispatch; matrix build x64 (windows-2025), arm64 (windows-11-vs2026-arm), x64-cuda, x64-sycl (150 min); `verify` job on ubuntu writes SBOM; `scripts/ci/build-windows-tester-bundle.py`, `check-windows-bundle-imports.py` (PE import check: no DLL outside Windows/own dir); MSVC `/MT` static CRT (ADR-1503 r7), CUDA zip ships no NVIDIA file (`nvcuda.dll` = driver's), SYCL zip needs `/MD` -> ships MSVC redist DLLs unmodified + Intel `credist.txt` files + self-built Level Zero loader (ADR-1566); `run.cmd` refuses wrong arch; SmartScreen documented.
- Compression: images zstd (Docker >=23.0 to pull), zips zopfli (ADR-1591/1594, Research-2142). Doc says Docker 23.0+.
- Size: CPU image 1.05 GB on disk / ~270 MB pull (ADR-1492); Intel ~0.95 GB pull (ADR-1505).

### A.4 Licence handling (ADR-1503 + Research-2133)

- Audit of published bytes found: no licence texts for BSD/ISC/MIT parts, python-build-standalone `install_only` without texts, GPL/LGPL Debian + LGPL libquadmath wheel libs without source, no SBOM, libgomp without copyright.
- Rules: (1) ship only what report needs, vendor binaries unmodified (no strip/patchelf), driver from host; (2) every file has recorded licence in `tools/rc1-tester/image/licensing.json` (dpkg ownership + `/usr/share/doc/*/copyright` kept; pip dist-info; grafted libs by ELF build-ID + source pkg; VMAFx licences read from SPDX headers of files the build compiled via `ninja -t deps`); (3) gate `licensing.py check` fails the image build (`licence-check` stage) on unclaimed file / no copyright / no source for copyleft graft / undeclared compiled licence / stale notices; (4) `licenses/THIRD_PARTY_NOTICES.txt` + texts inside artifact (`/opt/vmafx/licenses/`); (5) copyleft source published beside artifact: `<image>:<tag>-source` (Debian source pkgs at installed versions incl. Built-Using + non-distro archives by URL+SHA256), archive gets source tarball on same release; component whose source cannot be identified is not shipped; (6) Syft v1.51.1 SPDX SBOM, attested on digest with `actions/attest` (attest-sbom deprecated); (7) vendor runtimes: NVIDIA only CUDA EULA Attachment A files, unmodified, derived images use digest-pinned `-runtime`/`-base` never `-devel`, pass on DLC licence; Intel only `credist.txt` files under EULA 2.1.D; AMD ROCm MIT/NCSA/Apache parts, `libnuma1`/`libelf1` source into companion; ROCgdb/trace-decoder/AOCC/compiler never ship; Microsoft static `/MT`, DLLs only from `VC\Redist\MSVC\...\Microsoft.VC14x.CRT`, never debug_nonredist, UCRT never; (8) fixtures only with recorded licence; BBB CC BY 3.0 notice text (4(a)/4(b)).
- Alternatives rejected: hand NOTICE no gate; REUSE-only (repo not artifact); Syft licence fields as record; GPL 3(b) written offer; pointing to snapshot.debian.org.
- Research-2140 production audit (ADR-1513/1514/1578): 18 findings, 12+ "breaks": ROCm image redistributes non-redistributable `librocprof-trace-decoder.so` + whole 20.9 GB dev image incl. ROCgdb; vmafx-node FFmpeg built `--enable-nonfree` ("not legally redistributable") -> package deleted (ADR-1578); GPL-3 FFmpeg + x264/x265 without licence text/source; 40 Debian libs `cp -L`'d without copyright; Go modules without NOTICE; rclone `vcs.modified=true`; Intel runtime without pass-on terms; models without licence texts. Lesson: licence work done AFTER first publication forced withdrawal of rc images.
- ADR-1514: FFmpeg never `--enable-nonfree`; published GPL-3.0-or-later; `-source` image = patched tree via `git archive` after `git am` + patch series + configure line (`CONFIGURE.txt`); `record-copied-debian-libs.sh`; Go modules via `.go.buildinfo`, MPL/LGPL module zips with dirhash == binary h1: sum. Verified by vmafx research (post1-licensing-research §A.6): n9.0.2 `configure` dies on `gpl` + any nonfree item; nonfree lists = cuda_nvcc, cuda_sdk, decklink, libfdk_aac, libmpeghdec; libvpl on hwaccel list, header licence MIT; AMD AMF licence NOASSERTION, read full text before AMF.
- ADR-1250/1699 (EUPL-1.2 root; LICENSE = EUPL, NOTICE = Netflix BSD-2-Clause-Patent), Research-2143 (licensee detection of root files; package manifest licence fields must equal union of shipped files; LICENSE-MIT published in which artifacts). REUSE.toml + LICENSES/*.txt; `lint-reuse` (reuse 6.2.0).

### A.5 Signing / attestation (all tester artifacts)

- Image: cosign v3.1.3 keyless sign of index; `attest-build-provenance` (SLSA v1) per digest; SPDX SBOM `actions/attest`; `gh attestation verify oci://...` in publish job; tester doc shows `cosign verify` + `gh attestation verify`.
- Archives: `cosign sign-blob --bundle <f>.sigstore.json`; provenance; `<name>.spdx.json` asset attested on archive. Ad-hoc codesign macOS; no notarisation/Authenticode (SmartScreen documented).
- Production releases additionally: release blobs, wheels (PEP 740), images (docs/development/release.md; ADR-1356, 0902).

### A.6 RC process (ADR-1201, 1348, 1341, 1421, 1490, 2001, 2198)

- Tag shape narrow: `vX.Y.Z-rc.N` only (rc, dotted integer, no leading zero); six guards relaxed (verify-release-version.sh, supply-chain.yml x2, docker-publish-production, operator-node); tag and GitHub `prerelease` flag must agree; RC can never take `latest` (explicit refuse in docker-publish-production); contract gate treats `-` manifest as pre-1.0.0 (sort -V trap: `1.0.0` sorts before `1.0.0-rc.1`). Rationale: RCs exercise signing/SBOM/SLSA/image publication for real; drafts rejected because draft never fires `release: published`.
- Numbering: release-please `versioning: prerelease`, `prerelease-type: rc` (ADR-1348; default strategy would open 1.0.1-rc.1). Flow: push to master -> release-please maintains one release PR -> merge creates DRAFT release -> authenticated human publishes draft -> tag + `release.published` -> publication workflows check out immutable tag, sign/attest/smoke before publish. `.release-please-manifest.json` holds current rc. Final: `prerelease:false`.
- Candidate meaning: map in docs/development/release.md (rc1 correctness + tester path; rc2 dep train; rc3 twin exactness; rc4 Rust path; rc5 dedup; rc6 GPU capability table; rc7 CPU table; rc8 bench/tune; rc9 retrain). Each row has "Proves / Must not claim". Testers feed rc evidence: hardware reports close `docs/state.md` rows (ids in hardware-needs.json).
- Gate (ADR-2198): `scripts/release/candidate-legs.json` lists every tester leg (4 Windows build + 4 verify jobs, macOS build, 6 tester-image jobs); `scripts/release/check-candidate-legs.py` requires each `success` in a completed run on the EXACT commit (push/schedule on that commit, or dispatch whose `run-name` carries the full SHA; skipped/absent/red = fail); runs in `Release Script Contract` on a release PR labelled `autorelease: cut`, vs PR base commit; cut procedure dispatches legs first. Plus six process gates in rule-enforcement.yml; `verify-native-release-artifacts.sh` clean-env verifier; `release-dry-run.yml` weekly.
- Tester feedback intake = hardware_report.yml form + PR to docs/hardware-reports; bug_report.yml, performance_regression.yml, accessibility.yml also exist. No separate rc-feedback template.
- Published rc images later found non-compliant: `tools/rc1-tester/image/published-rc/{artifacts.json,scans/}` records them (ADR-1578).

### A.7 CI cost notes

- Path-scoped: `own_paths_only` selectors (ADR-1700) so only tester-input changes build; nightly amd64 CPU only (~00:29-03:09 UTC window); GPU legs build+no_device only; Windows zips build on master push; macOS weekly. Timeouts 90/120/150 min. Unit/lint of tester code: nox `rc1_tester` session + required hosted job.

- `.github/workflows/`: `ci.yml` (jobs core, ffmpeg-stack, sanitizers, windows [MSYS2 UCRT64, windows-2025, libpelorus + fast suite], docs), `release.yml` (tag `v*` or dispatch; ci -> release-build -> publish: `gh release create` of patch tarball + SPDX SBOM + provenance + SHA256SUMS + cosign sig; NO `--prerelease` flag; tag==meson version check in release-build), `release-build.yml` (SLSA v1 attest, cosign keyless, SBOM via anchore/sbom-action), `devcontainer-image.yml` (`ghcr.io/vmafx/pelorus-dev`, PR build, master push+attest; base `.devcontainer/base/Containerfile`), `standards-gate.yml`, `praetor-docs.yml`.
- Artifacts released: `pelorus-ffmpeg-patches-<tag>.tar.gz` only (series.txt, README, 0*.patch, files/). No binaries, no images, no FFmpeg build published.
- Test/bench assets: `ffmpeg-patches/test/build-and-run.sh` (needs local `FFMPEG_REPO`; replays 18-patch stack on pinned n9.0.2 946fcce0; configure `--enable-vulkan` + auto `--enable-libvpl|libaom|libsvtav1`, `--disable-doc`; NVENC if headers; verifies bsf `pelorus_fgs`, encoder options `pelorus_roi|pelorus_me_hints|pelorus_film_grain` on h264/hevc/av1 qsv, nvenc, vulkan, libaom, libsvtav1; static libavfilter consumer; sidedata/mc-stats tests), `vulkan-format-matrix.sh` (ADR-0147; env `FFMPEG_BIN VULKAN_DEVICE OUTPUT_ROOT PELORUS_VALIDATE=auto|1|0`; Khronos validation layer; hwupload/hwdownload round trips per format), `qsv-roi-regression.sh`, `pelorus_sidedata_test.c`, `mc_stats_test.c`, `static-libavfilter-consumer.c`, `scripts/bench/{bench.sh,run-bench.py,fetch-corpus.sh,corpus.lock,bd_rate.py,plot_rd.py}` (needs ffmpeg+pelorus, vmaf CLI, Vulkan GPU `DEVICE=vk:0`, network for corpus; clips bbb 640x360 48 frames, synth-banding via lavfi, netflix-bar; encoders hevc_nvenc av1_nvenc; preset p5; CQ 28 34 40 46), `scripts/test-*.py`, `scripts/check-*.py`, `scripts/release/concat-changelog-fragments.sh`.
- Docs: `docs/development/{build,benchmarking,bench-results,grain-ladder}.md`, `docs/backends/{vulkan,qsv-roi,libaom-roi}.md`, `docs/usage/{ffmpeg,anime,grain-fgs-bsf}.md`, `docs/architecture/overview.md`, `docs/research/*` (0147 Vulkan storage domain etc.).
- Issue templates: bug_report.yml, feature_request.yml, config.yml. No hardware_report. No `docs/hardware-reports`. No tester image/zip/bundle. No rc tags (tags v0.1.0..v0.2.2; v0.3.0 pending). No REUSE.toml / LICENSES / SPDX headers / third-party notices (per roadmap research); LICENSE = BSD-2-Clause-Patent (2026 Lusoris), EUPL-1.2 relicense PR in flight; FFmpeg-tree files (`ffmpeg-patches/files/*.c`, shaders) carry LGPL-2.1-or-later FFmpeg headers.
- Hardware actually available to project (maintainer inventory): RTX 4090 (NVENC + Vulkan), Arc A380 (Intel, ANV), RADV (AMD), B580 + UHD 770 on "office box" (PR #68 open: Intel validation, ADR-0150). Windows CI job exists (libpelorus only, no FFmpeg).
- Pelorus-specific facts that change the tester design vs vmafx:
  - Compute path is Vulkan (SPIR-V compiled at FFmpeg build time, ADR-0143), not CUDA/SYCL/HIP: one binary covers all vendors; vendor split is in the ENCODER and the Vulkan driver (NVIDIA proprietary ICD from host; Intel ANV and AMD RADV are Mesa user-mode drivers that would live INSIDE the image).
  - Product is a patched FFmpeg binary (derivative of FFmpeg), so redistribution of a binary triggers FFmpeg's licence (LGPL-2.1+ or GPL), unlike vmafx's own tools.
  - Value is BD-rate (needs bench + vmaf oracle) as well as correctness; vmafx deferred bench to RC8 for its testers, Pelorus cannot fully defer it.
  - Encoder steering matrix: NVENC (0004/0008/0011), QSV (0005), Vulkan encode (0009), libaom (0012), SVT-AV1 (0013). No VAAPI/AMF patch: AMD encode path = Vulkan video encode on RADV.

## C. Design mapping for Pelorus

Sizes S (<1 day agent), M (1-3 days), L (>3 days / needs hardware or external accounts). "prec" = vmafx precedent.

### C.0 Cross-cutting decisions (ADR first, `scripts/adr/next-free.sh --claim`)

- D1. Principle ADR: tester artifacts are evidence for a master commit, not a release; built by dispatch on master behind GitHub environment `tester-publish` (maintainer approval); GHCR under existing public package; prerelease name `tester-<date>-<sha8>`. prec ADR-1492/1493. S. NOTE environment + ruleset creation is a forge write for the maintainer (Pelorus rulesets are Praetor-managed: `praetorctl sync --remote`).
- D2. Licence rule ADR (copy of ADR-1503 rules scaled): ship only what report needs; recorded licence per file; gate fails image build; notices inside artifact; `-source` image; SPDX SBOM attested; never `--enable-nonfree` / `--enable-cuda-nvcc` / libfdk-aac / decklink; vendor files unmodified. prec ADR-1503, 1514. M (includes T1). MUST land BEFORE first publication (vmafx had to withdraw rc images, ADR-1578).
- D3. Package-name/namespace: `ghcr.io/vmafx/pelorus:<describe>-tester[-<vendor>]` under a package that is already public (vmafx: a new GHCR package starts private and visibility cannot be changed via API; `pelorus-dev` exists but is a different image). Needs one-time manual create+publicise of package `pelorus`; alternative reuse `pelorus-dev` package with tag suffix (pollutes dev image). OPEN.

### C.3 FFmpeg flavour decision (D4)

- Option G: GPL-3.0-or-later (`--enable-gpl --enable-version3`), as vmafx-node (ADR-1514); needed only if x264/x265 baselines are wanted in bench; combined work licensed GPL-3.0+, libpelorus EUPL-1.2 is GPL-compatible (EUPL Appendix lists GPL v2 and v3; verified in vmafx `LICENSES/EUPL-1.2.txt`). Static link simple.
- Option L: LGPL-2.1-or-later (no `--enable-gpl`): all needed components compatible (libaom BSD-2, SVT-AV1 BSD-3-Clause-Clear + AOM patent licence, libvpl MIT, Vulkan headers/loader Apache-2.0/MIT, nv-codec-headers MIT); EUPL-1.2 Appendix also lists LGPL v2.1 and v3 (verified), so libpelorus linked into LGPL libav\* is allowed by the Appendix mechanism; LGPL relink requirement met by shared libav\* in image + `-source`. Fewer obligations (no x264 GPL source), but x264/x265 reference arms impossible.
- Recommendation: L as default tester image; G variant only if the bench subset needs x264/x265 (separate tag). Both: never nonfree; `-source` image mandatory. Needs legal confirmation of EUPL<->LGPL linking position: NOT legal advice, UNVERIFIED beyond the Appendix text.
- Pelorus-side obligations to settle in T1: libpelorus public headers EUPL-1.2 vs FFmpeg-tree `.c` LGPL-2.1+ (vmafx precedent REUSE.toml:47-95 patches 0001-0018 LGPL-2.1-or-later, 0019 `LGPL-2.1-or-later AND GPL-2.0-or-later`); `ffmpeg-patches/files/vulkan/*.comp.glsl` SPDX; interop mirror vendored in vmafx stays BSD-2-Clause-Patent per ADR-1250 veto 4 until re-vendor (same-day update list in roadmap research §A.5).

### C.4 Licence constraints (checklist for T1/T17)

- Never `--enable-nonfree`, `--enable-cuda-nvcc`, `--enable-cuda-sdk`, libfdk-aac, decklink, libmpeghdec. Check built binary: `ffmpeg -L` and `-version` must not say "nonfree".
- No NVIDIA/AMD/Intel proprietary file in any tester image (host supplies). If ever shipping: only vendor-listed redistributables, unmodified, with EULA text and pass-on terms (ADR-1503 r7).
- Debian packages: keep `/usr/share/doc/*/copyright`; no `cp -L` of libs without `record-copied-debian-libs` equivalent (vmafx findings 5, 8).
- Source: `-source` image same package, same lifetime as image; includes patched FFmpeg tree exactly as compiled + `series.txt` + configure line + libpelorus commit; Debian source pkgs at installed versions incl. Built-Using.
- Fixtures: licence recorded; BBB CC BY 3.0 notice string; Netflix resources BSD-2-Clause-Patent text; netflix-bar source/licence UNVERIFIED (corpus.lock) - do not ship until confirmed.
- Notices inside artifact: `licenses/THIRD_PARTY_NOTICES.txt` + texts; names repo + exact commit (EUPL-1.2 Art. 5 distributor duty).
- Interpreters (if bundled for Windows): python-build-standalone `full` archive texts; HACL*/CPython `Doc/license.rst` notices (ADR-1503 r4).
- Microsoft: MinGW build avoids MS redist entirely (no UCRT shipping); if MSVC chosen follow `/MT` rule.
- SBOM: Syft SPDX on the artifact, attested; CycloneDX not required.
- Attestation covers provenance not authenticity of fixtures; say so as vmafx does ("no authenticity claim").
- Hardware reports: contain no hostname/serial/UUID/MAC/IP/PCI bus; Vulkan UUIDs must be dropped (vulkaninfo prints them).
