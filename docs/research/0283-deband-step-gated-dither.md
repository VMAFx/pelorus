# Why the pinned deband settings raised CAMBI on synth-banding

**Date:** 2026-10-19

**Decision:** [ADR-0225](../adr/0225-deband-step-gated-dither.md), issue [#283](https://github.com/VMAFx/pelorus/issues/283).

**Scope:** FFmpeg `n9.0.2` plus shared series `v0.3.0` plus the Pelorus stack, `hevc_nvenc` and `av1_nvenc` preset `p5` on an NVIDIA GeForce RTX 4090 (driver 615.78.08), vmaf 3.2.0 (`vmaf_v1.0.16`, `--feature cambi`). Clips: the pinned `synth-banding` (640x360, 24 frames, sha256 `aa1ec0f0…`, generated by `fetch-corpus.sh`) and `bbb` (640x360, 48 frames, source sha256 `1472c825…`) from `scripts/bench/corpus.lock`; the 10-bit run uses the v0.20 widening of `synth-banding` (`yuv420p10le`, sha256 `bbdfab0a…`).

Raw logs (local, not committed): `.workingdir/evidence/283/` (`sweep-v1.log` to `sweep-v6.log`, `emu.py`, `bench-before.log`, `bench-pinonly.log`, `bench-shaderonly.log`, `bench-after.log`, `tenbit-*.log`, `table.txt`, `isorate.txt`, `replay-r1.log`).

## Verdict

Three causes add up. NVENC quantises the hashed per-frame dither away at the pinned rates; a clamped tap at the plane border biases the tap average and flattens the border band; and grain on flat areas costs bits for nothing. Keeping taps inside the plane, adding dither only where a tap sees a code step, and pinning a static ordered dither brings mean CAMBI on `synth-banding` below the baseline for both encoders (hevc 1.76 against 2.97, av1 1.02 against 2.46). The price is bitrate at matched CQ (+10 % hevc, +33 % av1 against the baseline), CAMBI above the baseline at CQ 46, and +1.0 percentage point VMAF BD-rate on `bbb` with `av1_nvenc`.

## Method

1. `sweep.py` runs a variant list through the real GPU filter (or a prepared YUV), encodes each CQ point, decodes and scores VMAF and CAMBI against the source. Sweeps v1 to v6 covered dither mode, `dynamic`, `range`, `grainy`, edge handling and the step gate.
2. `emu.py` is a numpy model of the luma path of the shader (square taps, `blur=average`), with the edge handling and the gate as switches. Against the GPU output it matches 99.99987 % of pixels for the pinned settings (largest difference one code) and all pixels with `dither=none`. It produced the arms the shader did not have yet.
3. A noise floor: random ±1 changes on 5600 pixels of the source, seeds 1 to 4, gave hevc CAMBI 2.90 to 3.34 and av1 2.43 to 2.49 after the encode. A CAMBI difference smaller than that spread is not a result.
4. The final numbers come from `scripts/bench/bench.sh` itself, four times on fresh corpus directories: old build with the old pin (before), old build with the new pin (pin only), new build with the old pin (shader only), new build with the new pin (after). The new build passed the full replay (`ffmpeg-patches/test/build-and-run.sh`, 34 shared and 22 Pelorus patches).
5. The 10-bit check repeats the v0.20 command (`run-bench.py --pixfmt yuv420p10le --bitdepth 10`, `hevc_nvenc`, CQ 22 to 34) for both builds, with the filter defaults and with the new pin.

## Findings

- Without an encoder the filter works: CAMBI of the 8-bit clip goes from 2.13 to 0.00 with the pinned settings, and to 0.67 with `dither=none`.
- Every hashed-dither arm (pinned, static `bluenoise`, `range=31`, `dither=none`) lands above the baseline after the encode, outside the noise floor.
- Border bias: on the debanded first frame, row 0 has 168 of 640 pixels raised by one code, none lowered; the effect fades by row 40. Splicing the debanded border half or the debanded interior half into the source gives hevc CAMBI 3.31 and 3.32 against 3.59 for the full `dither=none` output, so each half carries about half of the rise.
- Sweep arms, mean CAMBI hevc / av1. Old shader on the GPU, static `bayer8` at the default `grainy=0.006`: 2.60 / 2.74 at 29.9 / 41.0 kbps. Model: edge fix only 3.46 / 3.03; edge fix plus step gate 3.54 / 2.80; edge fix, step gate and static `bayer8` at `grainy=0.012` 1.62 / 0.97 at 27.7 / 33.4 kbps. The bench run of the new shader reproduces the model within the noise floor (1.76 / 1.02).

## Consequence

The shader change and the bench pin land together (ADR-0225). The defaults stay: the shader fix alone does not bring the defaults below the baseline at these rates, and a change of defaults needs a real banding clip in `corpus.lock`. The `bbb` cost on `av1_nvenc` (+1.0 percentage point) is recorded, not hidden.
